# StudyLocker UI 美化方案 —— 「深色专注风」(Focus Dark)

> 目标：去掉"AI 味"，达到独立开发 App 的精致度。只改皮肤层，不动引擎/勇士/突脸逻辑。

---

## 1. 设计原则（去 AI 味清单）

| 原则 | 说明 |
|---|---|
| 零 emoji 图标 | emoji 全部替换为矢量 SVG 图标或纯文字；文案里的 🎉⚔️ 等一律移除 |
| 颜色只能来自色板 | 全站取色走 token，禁止散落 hex；状态色语义化（进行中/完成/警告/危险） |
| 三级字号与字重 | 标题 / 正文 / 辅助，禁止一锅粥；数字用等宽字形防倒计时跳动 |
| 控件有状态反馈 | hover / pressed / disabled / focus 环齐全，所有可点元素可见可感 |
| 卡片分组 | 学习 / 名单 / 统计三个功能域各一张"卡"，卡内再分组，减少视觉噪音 |

---

## 2. 色板（深色 Focus）

```
基底   bg          #0F1218    窗口底色（近黑蓝）
表面   surface     #171C24    卡片
表面高 surface-2   #1D242E    输入框/列表行底
边框   border      #262E3A    1px，卡片描边
分割   divider     #1F2733    卡内细分隔线

文字   text        #E8EBF0    主文字
       text-dim    #9AA4B5    次要（状态说明）
       text-faint  #5C6775    辅助（安全提示/时间戳）

主色   accent      #4C8DFF    主按钮/选中/链接/进度
       accent-hov  #639CFF
成功   success     #34D399    学习中/完成/解锁态
警告   warn        #F5A623    勇士之路/需注意
危险   danger      #F87171    停止/错误
文字于色上 on-accent #0F1218? → 白字 #FFFFFF / 深字按需
```

交互态规范：
- 主按钮：accent 底 + 白字；hover accent-hov；pressed 降 6% 亮度；disabled 40% 透明度
- 幽灵/次级按钮：surface-2 底 + border 描边；hover 底变 #232B38
- 危险动作（提前结束）：danger 描边幽灵钮，按下确认后变实心
- 卡片：surface 底 + 圆角 14px + 1px border；悬停卡片不升（静态为主）
- 焦点环：accent 50% 透明 2px 外描边（键盘可达性）

## 3. 字体与字号体系

| 用途 | 字体 | 字号/字重 |
|---|---|---|
| 倒计时大数字 | Bahnschrift（等宽数字，防抖动）/回退 Segoe UI | 64px / SemiBold |
| 页标题/卡片标题 | Segoe UI Variable / 微软雅黑 | 15px / SemiBold |
| 正文/按钮 | 同上 | 13px / Normal，按钮 13px / SemiBold |
| 辅助说明 | 同上 | 11.5px，text-faint |

倒计时等宽是关键细节：`45:00` 与 `4:59:59` 切换不跳动（Bahnschrift 数字天然等宽）。

---

## 4. 图标方案（替换全部 emoji）

| 现元素 | 替换为 | 说明 |
|---|---|---|
| ⚔️ 勇士之路 | SVG 盾牌（shield，线性风格 1.5px 线宽） | 状态色可变：平时 border 色，勇士中 amber |
| 🎉 完成横幅 | 无图标纯文案 "学习完成" + success 色点 | 徽章用 8px 色点，不用图标 |
| 📁/📄 名单行 | 行首 12px 小图标 folder/file 或省略 | 选中态行尾显"移除"钮 |
| 托盘图标 | 重绘 SVG：圆角方块 + 锁孔 + 底部状态色带 | 空闲灰 / 学习中 teal / 勇士 amber，肉眼可辨 |
| 窗口图标 | 同源 64px | |

SVG 全部内嵌字符串（`icons.py` 工厂函数 → QIcon），不依赖外部文件、可随主题换色。

## 5. 页面布局改造

### 学习页（主界面，重排为三张卡）

```
┌ StudyLocker ──────────────────────────────┐
│ 学习                 赦免应用    拦截统计   │  ← Tab 细胶囊样式
├───────────────────────────────────────────┤
│ ┌ 状态卡 ──────────────────────────────┐  │
│ │  ● 空闲 / 专注中 / ⚔ 勇士之路      │  │  ← 8px 状态点+文案，右侧剩余时长
│ └─────────────────────────────────────┘  │
│ ┌ 倒计时卡（居中，无按钮无边框干扰）───┐  │
│ │           01:23:45                    │  │  ← 64px 等宽大字，空闲时 "--:--"
│ │     开始于 21:30 · 剩余 42:13         │  │  ← text-dim 小字
│ └─────────────────────────────────────┘  │
│ ┌ 控制卡 ──────────────────────────────┐  │
│ │  时长 chips: (25) (45) (60) (90) + 45 分钟 │  ← 胶囊多选一
│ │  ☐ 开始学习时立即关闭其他应用         │  │  ← 样式化 checkbox
│ │  [ 开始学习 ]  ← accent 实心 44px 高  │  │
│ │  [ 提前结束 ]   ← 仅进行中可见(幽灵)  │  │
│ │  ──────── 勇士之路 ────────          │  │  ← 分隔+盾牌图标次级钮，下方琥珀说明条
│ └─────────────────────────────────────┘  │
│ 安全提示小字（text-faint，11px）          │
└───────────────────────────────────────────┘
```

- 横幅机制删除（原顶部整条彩色横幅）→ 改为状态卡内徽章 + 颜色语义，减少"警告条"感
- 引擎掉线/启动失败等异常仍需要醒目 → 状态卡变 danger/warn 底 + 文案（保留但收进卡内）

### 赦免应用页
- 搜索框（surface-2 圆角，带放大镜 SVG）
- 列表：圆角行（surface-2 底），行高 44px，名称 + exe 小字，hover 提亮
- 底部按钮组：主次分明（"从运行中的程序添加"为主按钮 accent 实心，其余次级）
- 数量徽章："已赦免 11 个"

### 拦截统计页
- 顶部统计卡：拦截总数大字 + 三种分类计数小 chip
- 自绘"分类横条图"（QPainter，无第三方依赖）：每类一行 = 名称 + 计数 + 渐变比例条（accent/success/warn/danger）
- 明细列表：时间戳弱化小字，拦截对象主文字，无边框表格感

### 对话框（HeroDialog / 确认框）
- 继承全局 QSS 自动深色；HeroDialog 确认输入框正确时边框变 success，错误时 danger + 微震动提示（可选）

## 6. 代码落地结构

| 文件 | 内容 |
|---|---|
| `locker/icons.py`（新） | SVG 字符串 → QIcon 工厂：shield/check/folder/file/power/play 等 ≤10 个 |
| `locker/theme.py`（新） | QSS 生成函数 `apply_theme(app)` + 色板 token（QSS 用 `qlineargradient` 与变量拼装） |
| `locker/ui.py` | 布局重排（卡片化）、emoji 移除、徽章、统计自绘；**保留全部现有控件引用名**（冒烟测试依赖） |
| `locker/scare.py` | 不动（全屏图片场景） |

回归：`ui_smoke.py` 必须全绿（控件名不变前提下）；随后重打包 4 exe 并更新发布目录与备份。

## 7. 里程碑

- **M1（效果最大）**：色板 + 全局 QSS + emoji 移除 + 学习页三卡重排 + 主按钮/时长 chips + 托盘图标重绘
- **M2**：名单页与统计页卡片化 + 自绘统计条 + 对话框细节 + 状态徽章
- M1 完成后先给你过目再动 M2（审美类改动分批确认，避免整版推翻）

## 8. 明确不做（防跑偏）

- 不做 Frameless 自绘标题栏/圆角窗口（系统缩放与拖动成本高，收益低）
- 不做动画表演（入场/页面切换动画克制，仅 hover/按压反馈）
- 不改功能结构：引擎、勇士、保险丝、突脸、日志全部原样
