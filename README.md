# StudyLocker 学习应用锁

Windows 个人专注工具：设定学习倒计时并选择"赦免应用"后，学习期间**任何非赦免、
非系统的程序一启动就会被立刻终止**（浏览器、IDE、记事本等学习工具可以正常用，
游戏、短视频客户端等则启动即被关）。

```
开始学习(倒计时) ──▶ 引擎实时拦截非赦免进程 ──▶ 倒计时归零 / 重启电脑 / 引擎退出
                            ▲                         │
                            └────── 全部自动解除锁定（fail-open，永不锁死）──────┘
```

## 设计原则

- **放行规则（顺序）**：自身/界面进程 → 系统目录（`C:\Windows`、WindowsApps 等）
  → 赦免名单（exe 文件或整个文件夹）→ 赦免应用的子进程（辅助进程不误杀）→ 其余一律
  **连同子进程树一并终止**。
- **重启电脑 = 紧急解锁通道**：锁定只活在进程里，关机重启后自然消失，开机即自由。
  引擎/界面崩溃同样自动解锁，绝不把你锁在系统外。
- **双通道拦截**：WMI 进程创建事件（近实时）+ 每秒全量扫描兜底，两者互不依赖。
- 引擎由界面以**管理员权限**（UAC）拉起，普通程序（包括低权限的你自己）杀不掉它，
  但界面退出不影响锁定——锁定独立于窗口存在。
- 本工具是给"冲动"加摩擦，不是监狱：拥有管理员权限的人物理上总能绕过
  （结束引擎进程、重启电脑）。它的意义在于**让你每次想逃学都要付出明确代价**。

## 安装与运行

1. 双击 `setup.bat`（自动创建 `.venv` 并安装 psutil / pywin32 / PySide6）；
2. 双击 `run.bat` 启动界面；
3. 在「赦免应用」页先把自己学习时要用的程序加进去；
4. 回「学习」页设好分钟数 → 点「开始学习」→ **允许 UAC 授权**（每会话一次）。

首次建议：先设 5 分钟做一次演练，确认自己要用的软件都能正常打开。

## 使用要点

| 操作 | 说明 |
|---|---|
| 开始学习 | 弹出 UAC 授权引擎；可选"立即关闭其他正在运行的非赦免应用" |
| 提前结束 | 确认后需等 10 秒（期间可「取消解锁」），再真正解锁 |
| 紧急解锁 | **直接重启电脑**（关机即解锁）；或结束引擎进程 |
| 学习中改名单 | 约 1 秒内生效（引擎每个循环重读会话文件） |
| 界面关了？ | 锁定继续；重开程序即可查看剩余时间或提前结束 |

第三方输入法（搜狗/百度等）不在系统目录里，若被拦截请把它所在文件夹加入赦免。

## 数据位置

所有状态在 `%LOCALAPPDATA%\StudyLocker`（测试可用环境变量 `STUDY_LOCKER_DATA` 覆盖）：

- `session.json` —— 当前会话（倒计时截止时刻、赦免名单、引擎 PID）
- `allowlist.json` —— 赦免名单（持久保存）
- `events.jsonl` —— 拦截/会话/异常日志（界面「拦截统计」页可见）

## 技术说明

- 拦截：WMI `Win32_ProcessStartTrace` 事件订阅（pywin32）+ psutil 轮询；
  终止：`TerminateProcess`（两次清扫子进程树，系统/受保护进程会跳过并记录）。
- 引擎（`engine_entry.py` → `locker/engine.py`）由 UI 经 `ShellExecuteW(runas)`
  提权启动，与界面进程分离；会话截止时刻写盘，界面消失也不影响计时。
- 测试：`tests/test_engine_logic.py`（放行决策，纯逻辑）、
  `tests/integration_engine.py`（真实进程强杀端到端）、`tests/ui_smoke.py`（界面冒烟）。

## 已知边界（有意为之）

- **微软商店应用（UWP，含商店版游戏）默认放行**：它们位于 `WindowsApps` 系统目录。
  想拦需要另做按包名（AppX family）的拒绝名单，v1 未实现。
- **赦免应用的子进程放行**：在受信应用（如已赦免的 VS Code）内启动的终端命令也会被
  放行——因为无法区分"语言服务"和"用户敲的命令"。这是防误杀换来的代价。
- 管理员权限的程序可以结束引擎（约等于重启解锁），属预期行为。
- 仅支持 Win10/11（用户态方案，家庭版可用；内核级 WDAC 需专业版，未采用）。
